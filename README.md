# Vishal Vibe Café Booking System

A café booking system developed using HTML, CSS, JavaScript, PHP, and MySQL. The project allows users to explore menu items, select seats, and book slots through a simple and interactive interface.

## Features

* Seat booking system
* Dynamic cart handling
* Menu browsing
* Booking slot selection
* Form validation
* MySQL database integration
* Data storage using PHP backend

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL
* XAMPP

## Project Structure

* `css/` → styling files
* `js/` → JavaScript functionality
* `php/` → backend processing files
* `images/` → project assets and images
* `data/` → booking data files

## How to Run

1. Install XAMPP
2. Place the project folder inside the `htdocs` directory
3. Start Apache and MySQL from XAMPP
4. Open the project in browser using localhost
